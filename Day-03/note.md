
>Personal Profile Website

A simple personal profile website built using HTML5. This project introduces who I am, my educational background, skills, teaching experience, interests, and contact information.

The main goal of this project is to practise the fundamentals of HTML and understand how different HTML elements work together to create a structured webpage.

## About the Project

This is my personal profile page, created as part of my journey into web development.

I wanted to build something meaningful instead of creating another generic HTML exercise. The website represents my academic background, teaching journey, personal interests, and future goals.

>Technologies Used

- HTML5
- Visual Studio Code
- Web Browser

No CSS, JavaScript, frameworks, or external libraries were used.

>Features

- Personal introduction
- Profile photograph
- Educational background
- Technical and professional skills
- Teaching experience
- Subjects I can teach
- Personal interests and career goals
- Contact information
- Internal navigation links
- External profile links

 >HTML Concepts Practised

1. HTML Document Structure

- `<!DOCTYPE html>`
- `<html>`
- `<head>`
- `<meta>`
- `<title>`
- `<body>`

2. Headings and Paragraphs

- `<h1>`
- `<h2>`
- `<h3>`
- `<p>`

3. Links

- `<a>`
- Internal navigation using element IDs
- Email links using `mailto:`
- Phone links using `tel:`
- External website links

4. Images

- `<img>`
- `src` attribute
- `alt` attribute
- `width` attribute

5. Lists

- `<ul>`
- `<li>`

>How to Run

1. Clone this repository or download the project.
2. Open the project folder in Visual Studio Code.
3. Make sure the profile image is named `profile.jpg`.
4. Open `index.html` in your browser.
5. Explore the different sections using the navigation links.

>What I Learned

Through this project, I practised:

- Creating a valid HTML5 document.
- Structuring content with headings and paragraphs.
- Adding images with alternative text.
- Creating internal and external hyperlinks.
- Organizing information using unordered lists.
- Understanding the importance of meaningful HTML structure.
- Building a webpage without relying on CSS or JavaScript.
