# Pixel Stories — A Responsive Creative Gallery

A small visual gallery made with HTML and CSS for Day 09 of the 99 Days of Coding challenge.

The idea was to turn the six provided photos into a neat editorial-style collection. I went with a dark background, warm accent color, large image cards and simple captions so the photos stay at the centre of the page.
>What I used-

- HTML5 for the page structure
- CSS Grid for the gallery layout
- CSS positioning for image labels and overlays
- Pseudo-classes for hover interactions
- Pseudo-elements for the image gradient overlay
- `auto-fit` and `minmax()` to let the grid adjust to the available space

>Run the project-

1. Download or clone the project.
2. Open the `Pixel-Stories` folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.

>Practice-

- Creating a multi-column layout with CSS Grid
- Controlling image card sizes and spacing
- Positioning labels over images
- Adding hover effects with `:hover`
- Creating a gradient overlay with `::after`
- Keeping the HTML structure readable
