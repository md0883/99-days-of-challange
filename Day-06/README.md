Day 06 — Introduction to CSS
Overview
Today, I started learning CSS (Cascading Style Sheets), which is used to style HTML webpages and make them more attractive and readable.
After building the basic structure of a webpage with HTML, I used CSS to work on its appearance, including text styles, colors, and font sizes.
Topics Covered
1.	Introduction to CSS
2.	CSS Selectors
3.	CSS Colors
4.	CSS Units
5.	CSS Typography
Practical Task
Task: Style a personal profile webpage using CSS.
For this task, I created a simple personal profile page with HTML and connected it to an external CSS file. I used different selectors, colors, units, and typography properties to improve its appearance.
Project Files
File	Purpose
index.html	Contains the structure and content of the profile page.
style.css	Contains the CSS rules used to style the webpage.
note.md	Contains the learning notes and explanations from Day 06.
What I Practiced
·	Connecting an external CSS file to an HTML document.
·	Using element, class, ID, universal, and grouping selectors.
·	Applying colors to text and backgrounds.
·	Using different CSS units such as px, rem, and %.
·	Changing font family, size, weight, and text alignment.
·	Styling a personal profile page with basic CSS.
How to Run the Project
1.	Download or clone this repository.
2.	Open the Day-06 folder.
3.	Open index.html in your browser.
4.	Make changes in style.css and refresh the browser to see the updates.
