# Day 07 — CSS Box Model, Margin, Padding, Border & Display

Topics Covered

- CSS Box Model: Understanding how an HTML element is structured.
- Margin: Creating space outside an element.
- Padding:Creating space between the content and its border.
- Border:Adding a visible boundary around an element.
- Display:Controlling how elements behave in the page layout.

>Practical Project: The CSS Learning Corner

I created a simple card layout featuring three learning cards:

1. HTML Foundations
2. CSS Styling
3. Creative Practice

Each card uses borders, margins, and padding to create a clear structure. I also used `inline-block` to place multiple cards beside each other while allowing them to wrap naturally when space becomes limited.

>What I Learned

- How the CSS Box Model works.
- The difference between margin and padding.
- How borders contribute to an element's total size.
- How block, inline, and inline-block elements behave.
- How to build a basic card layout without using Flexbox or Grid.
